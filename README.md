# Portals plugin for Codex

Build, manage, and publish [Portals](https://portals.to/) browser games from Codex —
the `portals-web-games` MCP server plus skills carrying the platform documentation.

## Install

```sh
codex plugin marketplace add portals-labs/portals-plugin-openai
codex plugin add portals-plugin-openai@portals
```

Then start a new Codex session — an open one does not see a freshly installed plugin.
The MCP server is a self-contained bundle that needs Node 18+ and no install step.

Refresh a later release with `codex plugin marketplace upgrade`, then
`codex plugin add portals-plugin-openai@portals` again.
